Підключення клієнта

  1. Запустіть цей сервер (start.bat).
  2. У клієнті MetaList встановіть API: localStorage.setItem('ms_auth_api','http://127.0.0.1:8787') або meta ms-auth-api / window.__MS_AUTH_API__.
  3. У Налаштуваннях: «На сервер» / «З сервера» для JSON клубу (роль coach або player).
  4. Опційно: TELEGRAM_BOT_TOKEN для бота клубу (див. BOT_SETUP.md).
